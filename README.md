# كشاف — Flutter

تطبيق كشاف بسيط بواجهـة عربية، يحتوي على:
- تشغيل وإيقاف فلاش الهاتف.
- وضع SOS يومض الفلاش تلقائياً.
- ضوء الشاشة كخيار إضافي.

## التشغيل
1. ثبّت Flutter.
2. من داخل المشروع نفّذ: `flutter pub get`
3. نفّذ: `flutter run`
4. لبناء APK: `flutter build apk --release`

ملاحظة: يحتاج التطبيق إلى إذن الكاميرا لأن Android يستخدم واجهة الكاميرا للتحكم في ضوء الفلاش.
